# cuddleya.de

Öffentliche Seiten der App Cuddleya: Start, Datenschutz, Impressum, Support (Deutsch, Englisch unter `/en`).

Die Inhalte stehen in `_src/<sprache>/<seite>.html`, Kopf und Fuß erzeugt `_build.py`:

```
python3 _build.py
```

Danach die erzeugten HTML-Dateien mit einchecken. Ordner und Dateien mit Unterstrich liefert
GitHub Pages nicht aus. Keine Cookies, keine Skripte, keine fremden Schriften: Das sagt die
Datenschutzerklärung zu, und dabei soll es bleiben.
